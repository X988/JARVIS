# Backup и восстановление

## Сам JARVIS

Остановить консоль. Скопировать каталог `data/` (audit и лимиты) и файл базы, если он появился после `npm run db:migrate`.

Проверка копии: поднять пустой каталог, `npm ci`, вернуть `data/`, выполнить `npm run db:migrate`, открыть `/ready`. Целостность журнала: `verifyAudit()`.

Это локальная копия. Отдельного ночного restore в пустую машину здесь не гоняли.

## SQL инфраструктуры

Успех backup — не появление имени файла. Нужны три факта: файл есть, размер больше нуля, `RESTORE VERIFYONLY` прошёл. Пробное восстановление только в одноразовую базу, не в `utp`.

Адаптера SQL в этой сборке нет. Команда `BACKUP` отсюда не отправляется.
