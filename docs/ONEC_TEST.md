# Тестовая 1С

В этой среде нет кластера 1С и конфигуратора. Загрузка расширения зелёной не считается.

Проверка, которая здесь есть: `FileOnecExecutor` читает и правит каталог `extensions/JarvisDev`. Это файлы, не база. `checkBsl` — fallback, не BSL Language Server и не `1cv8`.

Когда появится тестовая база, человек делает сам:

```
1cv8 DESIGNER /F "<тестовая база>" /LoadConfigFromFiles "<путь>/extensions/JarvisDev" -Extension JarvisDev
1cv8 DESIGNER /F "<тестовая база>" /CheckConfig -Extension JarvisDev
```

Откат: снять расширение `JarvisDev` в конфигураторе тестовой базы. Рабочую базу этой командой не трогать. Обновление конфигурации production DB отсюда не запускается.

Логи конфигуратора сохраняет человек рядом с прогоном. Пока их нет, отчёт о правке говорит только «выгрузка изменена».
