# Локальные документы

`indexFolder` читает выбранный каталог и режет текст на фрагменты. Разрешённые расширения: md, txt, pdf, json, yaml, csv, ps1, sql, py, ts, bsl, xml и конфигурации, включая `.rsc` и `.log`. PDF разбирается как набор строк в скобках. Файл не исполняется.

Пропускаются symlink, слишком большие файлы, имена и содержимое, похожие на ключ, пароль или токен. Фрагмент с фразой смены правил помечается `untrusted`. `knowledgeMayChangePolicy` всегда ложно.

`searchKnowledge` фильтрует роль, kind и дату. Роль `admin` видит все фрагменты; operator не получает документ, выданный только admin. `citeChunk` возвращает файл и строку. `syncKnowledgeIndex` сохраняет неизменённые файлы по mtime и размеру и удаляет фрагменты исчезнувших источников.
