# Telegram

Вход только по числовому id из `JARVIS_TELEGRAM_IDS` или карточки оператора. Username не является личностью. Чужой id получает `ACTOR_DENIED` до скачивания файла.

Голос: скачать, проверить размер, положить во временный wav, распознать, передать тот же `processCommand`. `update_id` входит в ключ идемпотентности вместе с оператором, повтор не исполняется второй раз.

Токен бота и webhook secret только в окружении. В репозитории их нет. Без `TELEGRAM_BOT_TOKEN` приём апдейта можно проверить тестом, исходящий Bot API не вызывается.
