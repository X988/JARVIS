# Модель угроз

Контур ещё demo. Ниже то, что закрыто кодом этой сборки, и что остаётся, пока нет боевых серверов.

| Угроза | Ущерб | Как закрыто | Что остаётся |
|---|---|---|---|
| Prompt injection | Модель собирает shell | Реестр намерен, произвольной команды нет | Модель всё ещё выбирает намерение по тексту |
| Command injection | Команда на хосте | Runbook выбирается сервером; SSH/WinRM используют фиксированные server-owned probes, без произвольной команды пользователя | Расширять только через зарегистрированные фиксированные операции и negative tests |
| Кража секрета | Пароли в git | `.env` в gitignore, в коде паролей нет | Секреты Codespaces ещё не заведены |
| Рост прав | Учётка 1С становится admin | Production deny, нет `Выполнить()` | Роль в тестовой базе назначает человек |
| Злой оператор | Чужой Telegram | Сессия cookie HttpOnly, роль из серверной привязки. Поля risk, role, approved и mode из браузера игнорируются | `JARVIS_TEST_AUTH=1` работает только вне production. В бою его быть не должно |
| Взятый хост JARVIS | Чтение audit и выгрузки | Выгрузка не содержит паролей | Хост с файлами расширения надо отделять от production |
| Взятая цель | Порча базы | Узкие adapters ограничены inventory/runbook/policy; отсутствие канала/credentials не подменяется успехом | Использовать least-privilege read-only accounts и отдельно live-verify каждую цель |
| Повтор запроса | Второй backup | `request_id` идемпотентен. Меняющий runbook ещё берёт `FileLockProvider` | Redis-провайдер без живого клиента lock не выдаёт. Для нескольких хостов нужен настоящий Redis |
| Поддельная заявка | «Да» вместо номера | Короткие согласия не принимаются. Заявка и hash параметров лежат в `data/approvals.json` | Протухшая заявка и смена параметров дают отказ |
| Компрометация поставки | Вредный пакет | `npm ci` из lock | Отдельного сканера подписи нет |
| SSRF | Запрос во внутреннюю сеть | Browser разрешает только allowlisted HTTP(S), блокирует loopback/private/link-local и проверяет DNS перед fetch; redirects запрещены | DNS rebinding остаётся отдельной границей: production egress должен дополнительно ограничиваться сетью/proxy |
| SQL injection | Порча базы | SQL adapter не принимает произвольный SQL; database/destination берутся из server inventory/config, backup выполняет фиксированный workflow | Live-проверка прав SQL service account и restore-test на изолированном instance обязательны |
| Порча audit | Стирание следа | Цепочка hash, файл только дописывается | Кто имеет диск, может подменить файл целиком. Нужна внешняя копия |
