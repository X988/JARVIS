# TTS

Серверный синтез не выдаёт себя за готовый. `KokoroTtsProvider` не подключён, потому что доступный Kokoro плохо говорит по-русски.

Ответ всегда имеет две части: короткий `voiceSummary` и технический результат pipeline. В голос не попадают ссылки, markdown и длинные хеши.

Barge-in считается по энергии: устойчивая речь около 200 мс останавливает воспроизведение, одиночный щелчок нет. Остановка в браузере делает `speechSynthesis.cancel`.
