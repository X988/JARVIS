# JarvisDev

Расширение 1С для контура development или test. Назначение: адаптация. Префикс собственных объектов: `jrvs_`.

Внутри:

- роль `jrvs_РазработчикТест` без прав администратора и без обновления конфигурации базы;
- общий модуль `jrvs_Разработка`, только сервер, не привилегированный, без внешнего соединения.

В рабочую базу это расширение не загружать. CF отсюда не собирается.

Загрузка в тестовую базу, из каталога выгрузки:

```
1cv8 DESIGNER /F "<каталог тестовой базы>" /LoadConfigFromFiles "<путь>/extensions/JarvisDev" -Extension JarvisDev
```

Режим совместимости расширения: 8.3.24. Если платформа старше, в `Configuration.xml` поменяйте `ConfigurationExtensionCompatibilityMode` на версию своей платформы и загрузите снова.

Язык `Русский` заимствован. Его идентификатор в основной конфигурации при первой загрузке конфигуратор может попросить сопоставить.
